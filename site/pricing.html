Pricing and hosting

Hosted pricing is not published.

This repository contains open-source RemboAI software. It does not advertise a managed subscription or confirm a hosted service offer.

Self-hosted deployment

Operators can deploy the backend from this repository. Hosting, database and Redis capacity, model API usage, messaging provider charges, and any payment-provider charges depend on the chosen infrastructure and accounts.

See the deployment guide and project README.

Payment handling

RemboAI supports configured M-PESA STK flows and owner-reviewed manual payment claims. Provider approval, transaction fees, credentials, and settlement behavior are controlled by Safaricom, Airtel, and the salon's own accounts.
